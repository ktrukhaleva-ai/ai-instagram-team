# AI-команда для Instagram-блога

Поэтапный проект для подготовки контента Instagram-блога с помощью специализированных AI-ролей.

## Первый этап

Сейчас создан только фундамент: структура проекта, единый формат задач и минимальный `Orchestrator`. Он умеет принять запрос и превратить его в понятный план работ. Контент, публикации и подключения внешних сервисов пока не создаются автоматически.

## Быстрый запуск

1. Откройте папку проекта в VS Code.
2. Скопируйте `.env.example` в `.env` и позднее внесите ключи сервисов.
3. В терминале выполните:

   ```powershell
   python main.py "Сделай Reel про ВПР для начинающих"
   ```

Программа выведет черновой план: цель, тема, аудитория и роли, которые понадобятся для выполнения запроса.

## Как устроен проект

```text
ai-instagram-team/
├── agents/                 # будущие AI-роли
│   └── orchestrator/       # первая рабочая роль
├── config/                 # настройки, не содержащие секретов
├── data/                   # исходные и подготовленные данные
├── knowledge/              # база знаний бренда и контента
├── skills/                 # повторно используемые инструкции для ролей
├── tests/                  # автоматические проверки
├── tools/                  # адаптеры к внешним сервисам
├── .env.example            # перечень будущих секретов
├── main.py                 # точка входа
└── requirements.txt        # зависимости Python
```

## Архитектурный принцип

Пользовательский запрос сначала проходит через Orchestrator. Он не создаёт контент сам: он формирует структурированную задачу и определяет, какие роли нужно подключить. Каждая роль в дальнейшем будет возвращать JSON-результат в одном формате.

```text
Запрос → Orchestrator → план работ → специализированные роли → проверка → согласование → публикация → метрики
```

## Связи с сервисами

Подключения будут добавляться по одному после проверки сценариев:

| Сервис | Назначение | Когда подключаем |
|---|---|---|
| GitHub | хранение кода и история изменений | после локальной проверки каркаса |
| Telegram | входящие задачи и согласование | после Orchestrator |
| Excel | контент-план и отчёты | после Content Agent |
| Figma | визуальные материалы | после базового контентного потока |
| ElevenLabs | озвучка | после сценария коротких видео |
| Metricool | публикация и метрики | после ручного согласования контента |
